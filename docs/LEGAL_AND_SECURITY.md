# Юридические страницы и безопасность (pet-проект)

## Что добавлено на сайт

- Политика конфиденциальности
- Условия использования
- Политика cookies
- Политика возврата (явно: оплаты нет)
- Согласие на обработку ПДн в форме заявки
- Баннер cookies (информационный)
- Плашка «это pet-проект» сверху сайта

## Cookies и аналитика

| Что | Есть? |
| --- | --- |
| Session / CSRF cookies Django | да, необходимы для корзины |
| Яндекс.Метрика / Google Analytics | нет |
| Рекламные пиксели | нет |
| Яндекс.Карты | только если задан `YANDEX_MAPS_API_KEY` |

Для необходимых cookies достаточно уведомления. Отдельный opt-in для маркетинга не нужен, потому что маркетинговых cookies нет.

## Сторонние сервисы

1. Шрифты Google Fonts (Montserrat, Exo 2)
2. Яндекс.Карты — опционально
3. SMTP — опционально через переменные окружения
4. Хостинг (Railway / Hugging Face / и т.д.)

## Проверка по типичным рискам

| Риск | Статус в проекте |
| --- | --- |
| Секреты в git | `.env` в gitignore, есть `.env.example` |
| API-ключ карт во фронте | ключ JS API по природе виден в браузере; хранится в env, не в репозитории |
| SQL через склейку строк | ORM Django, без raw SQL |
| Сырой HTML из описаний | `|safe` убран, вывод через `linebreaksbr` |
| Админка без логина | стандартная Django auth |
| CORS `*` | CORS не открыт |
| Rate limit | middleware на заявку и корзину |
| DEBUG и stacktrace наружу | `DEBUG=False` на проде |
| Пароли в открытом виде | Django PBKDF2 для админов; форма заявки паролей не хранит |
| Фейковые отзывы | на сайте нет блока отзывов |
